Featured Engineering Showcase

Student Learning Management System (SLMS)

A full-stack institutional platform engineered to streamline attendance logging, academic grade tracking, and parent communication loops through a unified relational schema.

Python Flask Microframework MySQL Database Role-Based Access (RBAC)

Multi-Tenant Campus Academic Core

Traditional academic record-keeping in colleges suffers from fragmented spreadsheets and delayed grade visibility. The SLMS centralizes student lifecycle data into normalized MySQL tables, providing role-segregated dashboards and automated notification channels.

Strict Permission Boundaries for 3 Tiers:

  • Admin: System configuration, batch student enrollments, faculty assignations, and institutional audit logs.
  • Faculty: Daily attendance roll-call, term mark entry, student performance flags, and report sheet exports.
  • Students & Parents: Read-only real-time metrics, cumulative percentage calculation, and automated shortage warnings.

Zero-Friction Daily Roll-Call & Analytics:

  • Session-based attendance logger cutting faculty input time from minutes to clicks.
  • Dynamic attendance percentage calculation with automated color alerts (<75% threshold).
  • Centralized SQL joins across courses, semesters, and individual student profiles.

Academic Performance Ledger:

  • Internal assessment mark entry with automated grade weighting and GPA projection.
  • Downloadable academic transcripts and tabular semester performance reports.
  • Visual trend indicators highlighting subjects requiring remedial support.

Automated Stakeholder Alert Channels:

  • Automated alert triggers when attendance drops below mandated university criteria.
  • Parent notification loop bridging faculty feedback with home guardians.
  • Eliminates end-of-semester shock by providing weekly transparency.
